SOBRE O PROJETO
---------------
A FocoEdit ajuda quem está começando a editar:
  - ALUNOS se cadastram para APRENDER, seguindo trilhas e treinando
    com exemplos de foto, áudio e vídeo;
  - MENTORES se cadastram para COMPARTILHAR DICAS de edição.

Por isso existem DOIS cadastros diferentes:
  - cadastro-aluno.html   (tema verde-azulado) -> o que quer aprender,
    nível atual, horas de estudo por semana e objetivo.
  - cadastro-mentor.html  (tema roxo)          -> área em que edita,
    anos de experiência, portfólio, programas e a primeira dica.

O site tem 10 páginas, e todas se ligam pelo menu do topo.

COMO O HTML E O CSS SE LIGAM
----------------------------
1) Cada página HTML usa o CSS de mesmo nome, por esta linha no <head>:

       <link rel="stylesheet" href="../css/fotos.css">

   O "../" significa "sair da pasta html e entrar na pasta css".

2) Os CSS se interligam: o index.css guarda o estilo comum a todas as
   páginas (cores, cabeçalho, menu, cartões, rodapé). Os outros 9
   arquivos começam com esta linha:

       @import url("index.css");

   Depois dela vem só o que é exclusivo da página.

3) As cores ficam no começo do index.css, em variáveis (:root):

       --cor: #5b4bdb;   (roxo principal)

   O cadastro do aluno troca essa variável no próprio CSS para ficar
   verde-azulado (#0b8272), e assim se diferencia do cadastro do mentor.


O QUE FUNCIONA NO SITE
----------------------
- Navegação: o menu leva às 10 páginas e marca a página atual.
- Dicas (dicas.html): clique em "Ler a dica" para abrir e fechar.
  Usa a tag <details>, sem JavaScript.
- Players: os áudios e os vídeos têm botões de play, pausa e volume.
- Formulários (cadastro-aluno, cadastro-mentor e contato):
    * os campos obrigatórios e o formato do e-mail são validados;
    * ao enviar, a página NÃO recarrega: aparece uma mensagem verde de
      confirmação;
    * nos dois cadastros, o nome fica guardado no navegador
      (localStorage) e a página Início passa a mostrar
      "Olá, <nome>! Continue de onde parou.".
- Nada é enviado a servidor: os dados ficam só neste navegador.
  Para apagar o nome guardado: F12 > Application (Aplicativo) >
  Local Storage > clique com o botão direito > Clear.

O JavaScript é curto e está dentro das páginas, no final do <body>
(index, cadastro-aluno, cadastro-mentor e contato), com comentários.
